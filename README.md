## ✨ أبرز المميزات (Key Features)

- 📱 Responsive Design: تصميم تجاوبي متوافق 100% مع كافة الشاشات (الهواتف، الأجهزة اللوحية، والحواسيب).
- 🌙 Dark / Light Mode: دعم كامل للوضع الليلي والنهاري لراحة العين أثناء التصفح.
- 🌐 Multi-Language: إمكانية التحويل بين اللغات بسهولة.
- ⚡ High Performance: سرعة فائقة في التحميل والاستجابة بفضل تقنية Vite.
- 🛒 Interactive UI: واجهة مستخدم سلسة لإضافة المنتجات وتصفح الأقسام.
